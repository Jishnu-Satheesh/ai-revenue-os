# Universal Agent governed workflows: staging verification

The approved implementation now connects the drawer to source evidence, governed report intake, and durable analysis work. This record covers hosted Supabase staging with an authenticated local Next.js app and a real Trigger.dev development branch. The subsequent [production worker deployment and canaries](production-worker-2026-10-04.md) establish worker release `20261004.1` against the existing staging data. Hosted web deployment and wider organization enablement remain pending.

## Scope and boundaries

- Approval: [2026-10-01 execution plan](../../superpowers/plans/2026-10-01-universal-agent-governed-workflows.md), [design §21](../../superpowers/specs/2026-09-24-universal-ai-agent-design.md#21-approved-governed-workflows-amendment-2026-10-01), [ADR 0075](../../../adrs/0075-durable-agent-turns-and-source-owned-capabilities.md).
- Advice receives the actual question, bounded preceding user questions, active goals/constraints, permitted shared Memory, Growth/campaign context, and source metrics. Model timeouts retain source recommendations or audit findings. Money in prompt evidence is explicitly marked as minor units.
- A real historical fallback records one separator marker with dates/reason. Failed or denied reads never become empty coverage. A selected channel audit binds supporting advice to that audit's period; an attachment keeps its exact branch, dates, and currency.
- Report bytes are private and SHA-verified. Reuse requires digest plus complete declared scope. Changed bytes and unresolved metadata use server-owned challenges. Upload, validation, projection, correction, and admission retain their source authority. Private signed TUS upload forwards the current member credential to Storage RLS; it stores no token in turn state. See the [official Supabase resumable-upload contract](https://supabase.com/docs/guides/storage/uploads/resumable-uploads).
- Background payloads carry identifiers. Database leases, current role checks, retry limits, challenge digests, approval receipts, ordered events, and the terminal-message fence govern work. Inactive thread retention uses an explicit 90-day cutoff; private staging expires after 24 hours and deletion must be acknowledged.
- Existing TinyFish qualification, privacy, and budget gates remain in place. These canaries did not initiate TinyFish research, publish campaigns, alter prices, or move money.

## Defects resolved during the canary

- Bound the Supabase RPC receiver during worker authorization.
- Forwarded the member credential alongside the signed resumable-upload token.
- Preferred canonical report-type names over broad provider aliases.
- Honored explicit dates and bound supporting advice to the selected audit scope.
- Bounded report lineage queries to 100 IDs; larger request lines failed at the hosted gateway.
- Replaced floating-point accumulation with decimal integer summation. Finer source components remain intact and can cancel to an accepted total; unsupported finer totals are still refused by the source finding contract.
- Kept a previous failed run from ending a newly dispatched assessment before claim.
- Included observations/data checks in narration readiness; zero problem findings does not mean an empty audit.
- Removed a full Digital Twin load where only an authorized timezone read was needed. An unavailable optional context read can no longer hide a ready source audit.
- Preserved useful source advice during model timeouts and kept shared Memory below restricted sensitivity.
