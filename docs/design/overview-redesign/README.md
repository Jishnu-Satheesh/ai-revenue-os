# Historical Overview report design

These artboards document the report-style Overview currently implemented by
`src/components/organizations/overview-report.tsx`.

On 2026-09-11 the user approved a new purpose: Overview is the home of the organization,
with prominent campaigns, creative assets and business identity. The next implementation
is governed by [the organization-home design](../../superpowers/specs/2026-09-11-organization-home-design.md)
and its execution/data/visual contracts. The report remains live until that plan is executed.

Keep these files as historical and rollback reference. They do not override the new approved
information hierarchy, and the new prototype is not proof of production implementation.
