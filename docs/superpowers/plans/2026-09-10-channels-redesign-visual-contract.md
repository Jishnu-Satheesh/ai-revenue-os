- **P10 Read-only and failure states:** real permissions, no windows, refused figures, partial availability, mixed currencies, network/save errors and pending states extend the happy-path prototype. These states keep the same geometry where useful but never fabricate values.
- **P11 Icons:** use the exact prototype SVG path geometry for landing-specific glyphs when an installed Lucide equivalent differs visibly. - **P12 Accessibility:** preserve the prototype's visible compact geometry with safe touch hit areas and accessible names. Key/provider hint/mapping history/alias scope move into Manage or View details; none is discarded. No new raw-source retrieval is added.
